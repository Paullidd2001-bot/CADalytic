# ADR 0001: Architecture Decision Record Format

- Status: proposed
- Date: 2026-09-15
- Decision owner:

## Context

What repository evidence or requirement creates the decision?

## Decision

State one concrete choice and its boundary.

## Alternatives considered

List credible alternatives and why they were not selected.

## Consequences

Record benefits, costs, risks, migration impact, and testing obligations.

## Revisit condition

State the evidence that would justify changing this decision.
